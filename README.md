# FitBite 🥗

面向想减脂、改善饮食并愿意自己做饭的中国年轻人，FitBite 把“冰箱里有什么”转化为“这一餐能做什么”的中式健康饮食决策。

> 项目状态：可本地运行的功能型 Demo，已完成“库存录入 → 菜谱匹配 → 详情决策”的核心闭环。

## 问题与产品目标

很多饮食工具从热量记录或通用菜谱开始，但真实做饭决策往往卡在更前面：用户不知道现有食材能做什么，也不想为一道菜额外购买大量原料。

FitBite 因此把核心任务定义为：**先根据真实库存缩小选择范围，再用步骤与营养信息帮助用户完成一餐决策。**

## 核心使用流程

1. 录入冰箱中的主食材，并选择厨房常备调料。
2. 系统统一食材名称和别名，计算菜谱与当前库存的匹配结果。
3. 优先查看“现在能做”和“还差 1–2 样主食材”的菜谱，也可按菜名或食材搜索。
4. 打开详情，核对主食材、调料、制作步骤及热量、蛋白质、脂肪、碳水信息后再决定是否制作。

## 已实现功能

- **库存驱动推荐**：按主食材判断可做性，并区分现在能做、缺 1–2 项和其他结果。
- **中文搜索与标准化**：支持菜名、标签、食材关键词检索；通过标准食材目录、别名和上下位关系降低同物异名造成的漏检。
- **菜谱详情**：展示主料、常备调料、分步做法，以及营养信息和数据可信度提示。
- **筛选与收藏**：支持全部、可做、轻盈和收藏筛选；收藏保存在浏览器本地。
- **结构化数据管线**：包含菜谱解析、标准化、校验、导入，以及营养映射与计算模块。
- **本地菜谱库**：仓库内当前导入 263 道中文菜谱，其中 HowToCook 114 道、EveryDay_Food 149 道。

## 一次真实自用验证

创建者曾录入鸡胸肉、西兰花、猪里脊、鸡蛋和豆腐，在多项匹配结果中自主选择煎鸡胸肉，并继续查看制作步骤与热量、蛋白质、脂肪、碳水数据。

这次验证跑通了从库存录入、结果筛选到查看做法与营养信息的完整链路，为下一步外部用户验证提供了可测试版本。

## 产品决策与数据质量机制

| 决策 | 具体处理 | 目的 |
|---|---|---|
| 从库存而非饮食记录切入 | 先回答“现有食材能做什么”，再提供营养参考 | 降低每餐选择成本，聚焦 Demo 的最小闭环 |
| 主食材与常备调料分开 | 主食材决定可做性，调料单独提示是否已备 | 避免因为盐、油等调料让推荐结果失真 |
| 建立食材标准层 | 维护标准名称、别名、上下位关系和调料展示映射 | 减少搜索漏检和内部代码直接暴露给用户 |
| 对营养结果设置护栏 | 缺少重量换算、营养映射或油量时，标记为不完整而非强行给出精确值 | 不把不可靠估算包装成精确数据 |
| 分批验收再扩量 | 项目方法规定每批先抽查 20 道，关注营养异常、检索覆盖、字段和步骤完整性 | 控制批量导入带来的质量风险；此项是项目方法，不是仓库内的完整抽检日志 |

Demo 阶段比较了 Recipe API、Edamam Recipe API 与 API Ninjas。综合中式菜谱覆盖、本地化成本、调用成本以及授权与缓存限制，选择先用可追溯的本地数据验证核心决策流程，再评估外部 API。

## AI 协作与个人贡献边界

本项目采用 **AI-assisted development（AI 辅助实现）**：Gemini、Codex 等生成式 AI 参与代码生成与修改，创建者负责产品定义、任务拆解、质量验收和迭代决策：

- 提出产品构想，界定目标用户与核心做饭场景；
- 将需求拆解为库存录入、食材匹配、搜索、详情和数据管线等功能；
- 定义菜谱、食材、调料、步骤、营养和溯源字段的验收标准；
- 编写 AI 任务指令，检查生成结果，并根据异常决定返工、补规则或暂停扩量；
- 对产品边界和优先级做判断，例如先完成本地 Demo，而不是过早接入外部 API。

## 技术与架构

- React 18、TypeScript、Vite、Vitest
- `src/core/ingredients`：食材标准化、别名解析与分类关系
- `src/core/matcher`：库存匹配、结果分组与关键词检索
- `scripts/pipeline`：Parse → Normalize → Validate 菜谱导入流程
- `shared/nutrition`：单位换算、营养计算、可信度与健康分层规则
- `data/recipes_imported.json`：前端使用的结构化本地菜谱数据

## 本地运行与测试

环境要求：Node.js 18+ 与 npm。

```bash
npm ci
npm run dev
```

开发服务器启动后，按终端提示打开本地地址。其他校验命令：

```bash
npm test       # 运行 190 项测试用例
npm run build  # TypeScript 检查并构建生产产物
```

当前验证结果：**190 / 190 项测试通过，生产构建通过**。测试使用受控营养夹具，可复现菜谱处理与营养计算结果。
