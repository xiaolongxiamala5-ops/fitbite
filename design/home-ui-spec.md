# FitBite Home UI Specification

## Visual Direction

Future Kitchen / Glassmorphism

目标：
一个根据冰箱已有食材，告诉用户今天能做什么的 AI 厨房助手。

## Main Sections

Home 页面包含：

1. Today Hero
- Today
- X dishes ready
- Based on your fridge

2. My Fridge
- 食材 chips 展示
- + Add Item

3. Pantry Summary
- 常用调料摘要
- 不作为主要内容

4. Available Now
- 推荐当前可做菜谱
- 图片
- 菜名
- Ready 状态
- 时间
- 使用冰箱食材说明

5. One Step Away
- 展示差一个食材即可完成的菜

## Visual Style

- 毛玻璃卡片
- 圆角
- 柔和阴影
- 温暖背景
- 手机 App 优先

## Important

不要设计成：
- 白底网页
- 后台管理页
- 普通菜谱列表
